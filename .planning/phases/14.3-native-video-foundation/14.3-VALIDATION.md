## Sampling Rate

- **After every task commit:** Run the **quick command** restricted to this phase's regex (`-R "rawdata\|video_fourcc\|ffmpeg_link"`)
- **After every plan wave:** Run the **full ctest suite** (catches regressions in Phase 14.2 video_sync, Phase 15 encryption, Phase 15.1 SPSC tests, etc.)
- **CI-only:** Binary discipline checks on the vendored dylibs (cannot run before 14.3-01 produces the binaries)
- **Before `/gsd-verify-work`:** Full suite + CI binary checks must be green
- **Max feedback latency:** ~5 s for the quick command; ~30 s for the full suite
