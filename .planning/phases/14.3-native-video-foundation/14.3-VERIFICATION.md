### SC-2: x264 Strings Analysis

`strings libavcodec.61.19.101.dylib | grep -E 'libx264|x264_'` returns only `x264_build`.

`x264_build` is a benign ffmpeg internal documentation string ("Assume this x264 version if no x264 version found in any SEI") embedded in ffmpeg's H.264 decoder help text — it is a configuration label, not a GPL linkage symbol. The `verify_ffmpeg_lgpl.sh` script correctly uses the stricter pattern `libx264|x264_encoder|x264_init` (not bare `x264_`) and exits 0. SC-2 passes.
