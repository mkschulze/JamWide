<objective>
Re-vendor LGPL ffmpeg + Cisco openh264 across the four target platforms (`macos-arm64`, `macos-x86_64`, `linux-x86_64`, `windows-x86_64`), ship a standalone LGPL-discipline gate (`scripts/verify_ffmpeg_lgpl.sh`) wired into CI, generalize `cmake/ffmpeg.cmake` to dispatch per platform, ship a `jamwide_use_ffmpeg()` helper that bakes in Apple-clang's `BEFORE PRIVATE` include discipline, and add a minimal `tests/test_ffmpeg_link.cpp` smoke test that proves the vendored libs dlopen + expose the `libopenh264` encoder. Existing macOS-x86_64 vendored tree is re-run once to clear the libX11 spurious dep that the spike never cleaned up.

Purpose: Unblock 14.3-02 (RawData send) and 14.3-03 (receive-dispatch fix) by giving Wave 2 plans a green LGPL substrate to reference; pre-empt the Apple-clang struct-ABI shadowing bug from biting v1.3 ffmpeg consumers.

Output: Four populated `libs/ffmpeg/{platform}/{lib,include}/` trees, a per-platform CMake dispatcher, a CI-callable LGPL discipline gate, an included helper macro, a JAMWIDE_VIDEO_SPIKE-gated smoke test, and a CI workflow step that runs the gate plus the smoke test on each platform runner.
</objective>
