## Accomplishments

- Cross-platform LGPL ffmpeg vendoring driver covers macOS x86_64+arm64, Linux x86_64, and Windows x86_64 from a single `scripts/build_ffmpeg_lgpl.sh`
- Standalone `scripts/verify_ffmpeg_lgpl.sh` runnable from CI and from CMake POST_BUILD — same gate, no drift
- Generalized `cmake/ffmpeg.cmake` no longer early-returns on non-Apple; dispatches per platform with parameterized library-file glob
- `cmake/jamwide_use_ffmpeg()` macro encapsulates the Apple-clang `BEFORE PRIVATE` include discipline so no future consumer can accidentally compile against `/usr/local/include`'s ffmpeg headers while linking the vendored libs (Landmine L6 mitigated by construction)
- `libs/ffmpeg/macos-x86_64/` regenerated free of the spike's spurious `/usr/local/opt/libx11/lib/libX11.6.dylib` dependency (spike Risk #4 closed)
- `tests/test_ffmpeg_link.cpp` `JAMWIDE_VIDEO_SPIKE`-gated ctest target proves the vendored libs `dlopen` and expose `libopenh264` encoder
- `.github/workflows/juce-build.yml` macOS-14 job gains `Vendor LGPL ffmpeg`, `Verify LGPL discipline`, and `ffmpeg link smoke test` steps

## Files Created/Modified

**Created:**
- `scripts/verify_ffmpeg_lgpl.sh` (150 LOC) — standalone LGPL+linkage gate; iterates every populated `libs/ffmpeg/<platform>/`; asserts no `libx264|x264_encoder|x264_init` strings; on macOS asserts `otool -L` deps only in `{@rpath, /usr/lib, /System, libs/ffmpeg/}`; on Linux asserts `ldd` deps not in `/usr/local|/opt|/home`; on Windows strings-check only; SKIPs unpopulated platforms.
- `cmake/jamwide_use_ffmpeg.cmake` — `macro(jamwide_use_ffmpeg <target>)` encapsulating Apple-clang `BEFORE PRIVATE` include discipline + `ffmpeg::lgpl` link in one call; `if(NOT TARGET ffmpeg::lgpl) FATAL_ERROR(...)` guard.
- `tests/test_ffmpeg_link.cpp` (~50 LOC) — `JAMWIDE_VIDEO_SPIKE`-gated smoke test; asserts `avformat_version() != 0` and `avcodec_find_encoder_by_name("libopenh264") != nullptr`; runs in <0.02s; wired as ctest `ffmpeg_link_smoke`.

**Modified:**
- `scripts/build_ffmpeg_lgpl.sh` (extended to 321 LOC) — cross-platform OS/ARCH dispatch; spike-only `.62/.62/.9/.60/.7` compat symlinks DELETED; per-platform install-name discipline.
- `cmake/ffmpeg.cmake` — per-platform dispatch (`if(APPLE) elseif(UNIX AND NOT APPLE) elseif(WIN32) else(FATAL_ERROR)`); `${_lib_glob}` parameterized; rpath POSIX-only; preserves the verbatim comment block explaining why `INTERFACE_INCLUDE_DIRECTORIES` is NOT set.
- `CMakeLists.txt` — `video_spike` now uses `jamwide_use_ffmpeg(video_spike)` instead of inline includes/links; new `test_ffmpeg_link` target inside `if(JAMWIDE_VIDEO_SPIKE)`; inline POST_BUILD strings-check REPLACED with `bash scripts/verify_ffmpeg_lgpl.sh` invocation.
- `.github/workflows/juce-build.yml` — macOS-14 job: 3 new steps (Vendor LGPL ffmpeg / Verify LGPL discipline / ffmpeg link smoke test); Configure CMake extended with `-DJAMWIDE_BUILD_TESTS=ON -DJAMWIDE_VIDEO_SPIKE=ON`.
- `libs/ffmpeg/macos-x86_64/lib/*` — regenerated artifacts; spike compat symlinks removed; libX11 dep cleared.

## Decisions Made

- **Task 4 deferred to v1.3** (user decision at human-verify checkpoint) — Phase 14.3 ships the substrate (script + verify gate + CI wiring); v1.3 produces the three non-mac-x86_64 trees when those CI lanes are exercised. Realistic default for the x86_64-Mac dev machine. SC-1 is partial after this plan (macos-x86_64 only of four target platforms populated); the substrate is what unblocks 14.3-02 and 14.3-03, which is the actual gating purpose of 14.3-01.
- Used `BEFORE PRIVATE` macro helper (NOT `INTERFACE_INCLUDE_DIRECTORIES`) per Landmine L6 — Apple-clang `-isystem` injection would corrupt struct ABIs at runtime.
- Deleted spike-only `.62/.62/.9/.60/.7` openh264 compat symlinks in the cross-platform script — anti-pattern flagged in `.continue-here.md`; these were one-off scaffolding for a single dev machine.
- Replaced inline POST_BUILD strings-check in CMakeLists.txt with `bash scripts/verify_ffmpeg_lgpl.sh` invocation — single source of truth between CMake POST_BUILD and CI step.
