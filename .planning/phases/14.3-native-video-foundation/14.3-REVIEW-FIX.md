### IN-03: verify_ffmpeg_lgpl.sh — silently passes ldd "not found" entries on Linux

**Files modified:** `scripts/verify_ffmpeg_lgpl.sh`
**Commit:** `519482e`
**Applied fix:** Added an explicit `ldd "$D" | grep -q " => not found"` check in the
Linux ldd loop, with an explanatory comment about the failure mode (the existing
awk pipeline reduces `"libfoo.so => not found"` to the bare token `"not"`, which
the `/usr/local|/opt|/home` grep does not match). A vendored .so with a broken
NEEDED entry (e.g. from a bad patchelf run) now fails the gate hard. Syntax checked
with `bash -n`; script exits 0 on this macOS machine (Linux leg SKIPs as expected
since `libs/ffmpeg/linux-x86_64/` is the v1.3-deferred platform).
